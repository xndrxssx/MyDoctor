# 💊 MyDoctor: Gerenciamento Inteligente de Medicamentos 💊

Sistema embarcado de alarme para auxiliar idosos em tratamento medicamentoso
Nosso time (Aurelio Ribeiro, Alysson de Jesus Alves e Gabrielle) desenvolveu uma solução para ajudar pacientes, especialmente os mais idosos, e cuidadores a manterem tratamentos em dia. O aplicativo oferece um sistema de alarmes e gestão de medicamentos, garantindo mais segurança e tranquilidade para os usuários e seus familiares. 👵👴

# 🛠 Tecnologias utilizadas:
- SwiftUI para a criação de uma interface intuitiva e acessível
- Node-RED para a automação e integração de dispositivos IoT
- Arduino IDE para controle do hardware no indicador LED de gavetas com medicamentos
- Cloudant para armazenar com segurança os dados dos pacientes

Nosso objetivo foi melhorar a qualidade de vida das pessoas, oferecendo uma solução simples e eficaz para a gestão de tratamentos médicos. 💡📱
